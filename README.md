# 📂 Offline Document Vault

A privacy-first, 100% offline document management application built with React Native and Expo.

> No Cloud • No Backend • No Account • No Tracking

---

## ✨ Features

- 📁 Organize documents into folders
- 🪪 Store Aadhaar, PAN, Passport, Driving License, etc.
- 📄 PDF and Image support
- 🔍 Fast local search
- 🖼️ Thumbnail preview
- 🎨 Modern Glassmorphism UI
- 🔒 Local-only storage
- 📱 Works completely offline

---

## 🚀 Tech Stack

- React Native
- Expo
- Expo Router
- Expo FileSystem
- Expo SQLite
- React Native Skia
- Reanimated
- Gesture Handler

---

## 🔒 Privacy

All documents remain on your device.

This application:

- ❌ Does not upload files
- ❌ Does not use a backend
- ❌ Does not require an account
- ❌ Does not track users
- ✅ Works fully offline
